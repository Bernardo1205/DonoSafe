# DonoSafe - Aplicación para la Seguridad Nocturna

## Descripción

**DonoSafe** es una aplicación diseñada para mejorar la seguridad de las personas, especialmente mujeres jóvenes, que regresan a casa durante la noche. La app ayuda a prevenir amenazas al permitir la creación de grupos de personas con destinos cercanos, proporcionar alertas sobre zonas peligrosas y ofrecer herramientas de emergencia. Está pensada para aquellos que salen de fiesta o necesitan desplazarse por la ciudad después de oscurecer.

## Objetivos del Proyecto

El propósito principal de **DonoSafe** es proporcionar una solución tecnológica que ayude a las personas a sentirse más seguras cuando se desplazan solas de noche. Los objetivos incluyen:

- **Identificar áreas de peligro:** Uso de un mapa interactivo para reportar y visualizar zonas peligrosas en tiempo real.
- **Formar grupos de usuarios:** Agrupar a personas con destinos similares para que regresen acompañadas, aumentando la seguridad en el trayecto.
- **Fomentar la colaboración:** Crear una red de apoyo en la comunidad para prevenir incidentes.
- **Métodos de verificación de confianza:** Garantizar que los usuarios sean personas confiables mediante autenticaciones y un sistema de reputación.

## Características Principales

### 1. Registro de Zonas Peligrosas
Los usuarios pueden marcar zonas peligrosas en un mapa y describir el tipo de peligro (por ejemplo, robos, áreas oscuras, etc.).

### 2. Formación Automática de Grupos
Cuando varios usuarios tienen destinos cercanos o rutas similares, la aplicación los agrupa automáticamente. Los usuarios pueden decidir unirse al grupo o no.

### 3. Botón de Emergencia
En situaciones de emergencia, los usuarios pueden presionar un botón que envíe una señal de alerta a otros usuarios o autoridades locales.

### 4. Métodos de Autenticación Segura
La aplicación implementa varios métodos para verificar la identidad de los usuarios, como autenticación mediante redes sociales y correo electrónico, así como un sistema de calificación y reseñas entre usuarios.
